# 🚀 Life OS

> **One unified application to manage your entire personal life.**

Instead of scattering tasks across one app, documents in another, vehicle records in note files, and subscriptions in spreadsheets, **Life OS** centralizes daily life operations in a single local-first dashboard.

---

## ✨ Features (v1.0 MVP)

- 🏠 **Intelligent Dashboard:** Aggregates pending tasks, upcoming renewal dates, total recurring financial outflows, and computes a dynamic **Life Score**.
- 🤖 **Contextual AI Insights:** Proactive banners warning of expiring documents, upcoming vehicle renewals, and task bottlenecks.
- ✅ **Task Management:** Categorized task tracking with priority badges (`HIGH`, `MEDIUM`, `LOW`), custom due dates, completion toggles, and persistence.
- 📂 **Document Vault:** Centralized metadata tracker for IDs, insurance, property, education, and vehicle papers with automatic 30-day expiry flags.
- 🧾 **Bills & Subscriptions:** Track monthly and annual subscriptions, recurring utility bills, auto-pay statuses, and projected monthly outflow.
- 🚗 **Vehicle Hub:** Track maintenance cycles, insurance dates, and PUC expirations with status indicators.
- 🚨 **Emergency Mode:** One-tap emergency card displaying critical blood group, medical conditions, and guardian contacts.
- 💾 **Local Data Ownership:** All data is saved on-device via `SharedPreferences` with complete JSON backup export.
- 🌗 **System Themes:** Seamless Material 3 light and dark mode support.

---

## 🛠 Tech Stack

- **Framework:** [Flutter](https://flutter.dev/) (Material 3)
- **Language:** Dart
- **Storage:** Local key-value storage via `shared_preferences`
- **Architecture:** Service-repository separation with dedicated storage layers
